# Madhav Ecommerce Sales Dashboard

## Project Overview
This project presents an interactive E-commerce Sales Dashboard developed using Microsoft Power BI to analyze sales performance, profitability, customer behavior, product categories, and payment methods.

## Dashboard Features
- Total Sales Amount
- Total Profit
- Total Quantity Sold
- Average Order Value (AOV)
- State-wise Sales Analysis
- Category-wise Quantity Analysis
- Monthly Profit Analysis
- Customer-wise Sales Analysis
- Payment Mode Analysis
- Sub-Category-wise Profit Analysis

## Tools & Technologies
- Microsoft Power BI
- Data Visualization
- Data Analysis
- Interactive Filters and Slicers

## Key Insights
- Maharashtra has the highest sales among the displayed states.
- Clothing contributes the largest share of quantity sold.
- COD is the most used payment mode in the dashboard.
- Printers generate the highest profit among the displayed sub-categories.
